# NMGrapher logo

The current logo follows the user-provided N+ badge: a white serif capital N and a separate smaller light-blue plus sign, centered on a dark-blue rounded panel. This replaces the earlier curved N as the main brand mark.

The surrounding mathematics includes Euler’s identity `e^(iπ) + 1 = 0`, the eigenvector equation `Av = λv`, the definite integral `∫₀¹ x² dx = 1/3`, and `P(t) = exp(tQ)` for a time-homogeneous continuous-time Markov chain. A wireframe Bloch sphere has coordinate axes, pole labels and a Bloch vector; a directed cycle connects states 1 → 2 → 3 → 1. The formulas and diagrams are illustrative logo details, most legible at full image size.
